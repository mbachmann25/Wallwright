# Wallwright

> Wallwright is a Windows wallpaper tool for people who believe “Fill,” “Fit,” and “Stretch” are not design choices but administrative failures. Position, scale, and crop your wallpaper properly, then persuade Windows to display it as instructed.

Wallwright is planned as a Windows desktop utility for precise wallpaper positioning, scaling, cropping, previewing, and application.

## Status

Wallwright is in **early specification and repository setup**. The application and its planned features have not been implemented yet.

Start with the [project documentation](docs/Overview.md) for the current product direction, open questions, and roadmap.
