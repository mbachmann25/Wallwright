# Wallwright documentation

Wallwright is a Windows desktop wallpaper utility for people who need more control than Windows' built-in placement modes provide. It is intended to support exact image positioning, scaling and cropping, with a preview before the result is applied.

The project exists to work around the limited placement behaviour offered by Windows through Fill, Fit, Stretch, Tile, and Centre.
