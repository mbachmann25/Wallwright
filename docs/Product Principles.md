# Product Principles

- The preview must match the final wallpaper.
- The user remains in control.
- Common actions should be obvious.
- Advanced controls must not make basic use complicated.
- Do not alter the source image.
- Windows integration should be reliable and reversible.
- Prefer a focused tool over feature bloat.

These principles guide product and technical decisions. When principles create a trade-off, record the resulting decision in [[Decisions]].
